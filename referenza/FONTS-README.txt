CASAVVENTURA - FONT REFERENCE

La reference raster non contiene i file font originali. Questi sono font reali
locali da usare come base coerente:

- Fredoka: titoli, card, CTA e navigazione pesante
- Nunito Sans: testi, descrizioni e paragrafi
- Patrick Hand: note e scritte doodle

Non sostituire questi font con serif generici o Arial.
